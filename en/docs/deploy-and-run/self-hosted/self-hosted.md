# Self-Hosted Deployment

Run integrations on infrastructure you manage.

- [Containerized Deployment](containerized-deployment.md) — Deploy WSO2 Agent Builder projects to Docker, Kubernetes, and Red Hat OpenShift using the Ballerina Code to Cloud feature.
- [VM Deployment](vm-deployment.md) — Deploy WSO2 Agent Builder projects as standalone JAR files on virtual machines for self-hosted production deployments.
- [Serverless Deployment](serverless-deployment.md) — Deploy integrations as serverless functions on AWS Lambda and Azure Functions.
- [GraalVM Native Images](graalvm-native-images.md) — Compile Ballerina integrations to GraalVM native binaries for instant startup and reduced memory.
