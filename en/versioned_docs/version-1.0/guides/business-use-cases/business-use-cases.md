# Business Use Cases

End-to-end tutorials that build an AI agent for a concrete business
scenario in WSO2 Agent Builder, from creating the agentic integration
to running and testing it. Each tutorial adds a different capability
to the agent:

- **Build a Customer Care Agent with MCP**: an agent that uses tools
  from a live MCP server to answer product and order questions.
- **Building an IT Helpdesk AI Agent with Persistent Memory**: an agent
  with a custom tool and MSSQL-backed memory that remembers
  conversations across restarts.

These are the Business Use Cases from the full catalog on the main
[Guides](/guides) page.
